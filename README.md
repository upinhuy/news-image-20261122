One image summing up the world's news of Sunday 22 November 2026: three lead
stories — the COP31 climate talks collapsing in Antalya, a suspected drone
strike on a Russian warship at Benghazi, and the capture of cartel boss
'El Chapo Isidro' in Mexico — above a UTC timeline of 47 further stories,
each labelled with the wire that reported it (Reuters, BBC, AP, Al Jazeera,
NYT, FT, CBC, DW, Guardian).

`main.ts` copies the committed `entry.png` to the output directory using only
the Node standard library. The image was drawn with `draw.py` (Pillow) from
stories reported on 22 November 2026; it is 1024×1024 PNG, deterministic
across runs.
